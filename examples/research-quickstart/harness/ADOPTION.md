# Research trial adoption record

Source: Seraph Harness Core, research-quickstart snapshot distributed with this folder.
Generalized source-harness baseline: v2.5.3.
Exact core revision: not recorded yet; on first use record the downloaded commit or
retain an immutable dated copy of this complete folder before changing it.

This is a manual trial. No hooks, automatic validators, updater or delegation engine
are installed. The agent follows AGENTS.md; the human checks its evidence and retains
publication authority.

## Ownership

- Baseline: `harness/PACK.md` and the original instructions supplied with this snapshot.
- Local work: STATE.md, logbooks, data, outputs and research-specific criteria.
- Updates: compare changes before replacement; preserve local criteria and records.

## Active controls

- Instruction loading: manual request to read AGENTS.md and STATE.md.
- Human-only actions: instruction plus human supervision; no technical blocker installed.
- Verification: manual, using the five verbs in PACK.md; evidence goes in the logbook.
- Session closure and recovery: manual STATE.md protocol, reviewed by the human.
- Delegation: not configured for this trial.
- Alerts: the human reads unresolved checks and the checkpoint at each session close.

## First-session checklist

- Record the copied core revision or immutable snapshot reference.
- Confirm the research question and source criteria with the human.
- Capture a real check result and its evidence before declaring any output verified.
- If automatic controls are added later, record activation tests and remaining gaps.
